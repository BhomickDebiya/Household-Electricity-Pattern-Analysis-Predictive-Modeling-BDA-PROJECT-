Industrial Smart Grid Challenges

  • RDBMS Scaling Limits: Millions of high-frequency smart meter readings cause disk saturation, index bloat, and concurrency lockups in relational databases.
  • Diurnal Grid Stress: Unscheduled peak surges destabilize grid frequencies, necessitating costly auxiliary peaker plants.
  • Sub-Meter Visibility: Utilities lack appliance-level disaggregation (HVAC vs kitchen) needed for dynamic time-of-use tariffs.

Project Engineering Objectives

  • Distributed Storage: Ingest 132.9 MB dataset into Hadoop HDFS across fault-tolerant block clusters.
  • Dual-Engine Execution: Run batch Java MapReduce on HDFS splits alongside in-memory Apache Spark analytics.
  • Dual-Engine Verification: Mathematically cross-validate that MapReduce and Spark produce identical averages (<0.0001 kW delta).
  • Predictive Intelligence: Train a Random Forest model to forecast next-hour demand with Cassandra persistence.

Native Java Implementation Classes

  • HourlyElectricityMapper.java: Parses semicolon delimiter, filters '?' tokens, extracts hour, and emits <Text(hour), DoubleWritable(power)>.
  • Shuffle & Sort: Core Hadoop engine groups values by hour key into Iterable<DoubleWritable>.
  • HourlyElectricityReducer.java: Computes sum(power) / count(minutes) and writes TSV output.

Why Combiner Cannot Compute Average Directly

Non-Associative Arithmetic:

Avg(A, B, C) ≠ Avg(Avg(A, B), C)

If a combiner computed local averages on unequal partition splits, the reducer would average those averages, yielding severe mathematical distortion. A combiner must emit (sum, count) tuples instead.

Electrical Engineering Principles
Multi-Sensor Correlation & Electrical Physics Laws

Active Power vs. Current (r = +0.999)

Empirically verifies the fundamental AC single-phase power law:

P = V × I × cos(φ)

Since grid voltage is regulated around 230-240V, active power consumption is directly proportional to current draw.

Active Power vs. Voltage (r = -0.40)

Negative correlation reflects real-world internal grid line drop (Ohm's Law: V_term = V_grid - I × R_line) during heavy appliance usage.

Climate Control Dominance (r = +0.64)

Sub-metering 3 exhibits the highest correlation with active power among all individual sub-circuits.

Viva Examination Preparation
High-Yield Viva Questions & Crisp Academic Answers

Q1: Why use both MapReduce and Spark?

Answer: MapReduce provides disk-streamed processing with minimal RAM footprint for baseline aggregations directly on HDFS splits. Spark operates in-memory using DAGs, enabling 100x faster iterative exploration and ML. Dual-engine validation proves both engines produce identical results (0.000000 kW delta).

Q2: Why can't a Combiner calculate Average?

Answer: Average is mathematically non-associative: Avg(A, B, C) ≠ Avg(Avg(A, B), C). Partial averages would skew the true mean. A combiner must emit intermediate (sum, count) tuples instead.

Q3: How does Cassandra handle Time-Series?

Answer: In hourly_aggregates, 'hour' acts as the Partition Key for O(1) hash distribution. In model_predictions, 'timestamp' allows write-optimized appending using Cassandra's LSM-Tree architecture.

Q4: Significance of r = +0.999 Active vs Current?

Answer: Validates P = V × I × cos(φ). Since grid voltage is regulated at 230V, active power is directly governed by current draw. The negative voltage correlation (r = -0.40) proves internal line drop under heavy loads.
